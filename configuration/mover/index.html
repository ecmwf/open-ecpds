    Data Mover: ecmwf.properties¶

    The Mover's ecmwf.properties configures its Master connection, public protocol listeners, data repository, retrieval behaviour and shared runtime. This reference includes options read by the implementation even if they are absent from the supplied template.

    See also the Master and Monitor references.

    File location and overrides¶

    The source template is etc/mover/conf/ecmwf.properties. Its RPM path is /usr/local/ecpds/mover/conf/ecmwf.properties; the launcher selects it with the ecmwf.properties JVM property.

    Use /etc/ecpds/mover.cnf or the container/service environment for launcher settings such as addresses, ports, operational mode and shared secrets. The template's ${...} expressions resolve JVM properties, section references or supported methods, not arbitrary environment variables.

    The final #include "${mover.etc}/ecmwf.properties" loads local overrides, normally from /etc/ecpds/mover/ecmwf.properties. This is an active directive, not a commented-out example. Do not include the file into itself. See the configuration syntax and loading rules.

    For example:

    [HttpPlugin]
maxThreads=200
minThreads=20
webdavEnabled=false

[SshPlugin]
maxConcurrentSessions=100

    Restart the affected Mover after changing service configuration unless a feature explicitly supports live updates.

    Reading this reference¶

    Code fallback means the reader's value when the option is absent, not the explicit shipped value. A dash means no assignment in the template. null means the reader supplies no fallback; it does not guarantee that omitting the setting is valid. Different reader fallbacks are listed separately, with source links. Java expressions are preserved for context-dependent defaults. Credentials are not reproduced.

    Rows marked template entry have no direct literal reader in this process's reviewed sources. Some entries are substitutions or retained compatibility settings; named-socket and open-map readers are described separately.

    Names are case-sensitive. Duration-reading options accept suffixes such as s, m, h and d; bare configured durations mean hours. Plain numeric socket timeouts are milliseconds. Rates in [TestModule] are bytes per second; file-content settings take a path, while their fallback is content.

    Operational guidance¶

    Public listeners, portal links and control-channel authentication are separate:

    • [PluginList] selects services to start; plugin sections configure them. Advertising a protocol in [DataPortal] does not start its listener.
    • [HttpPlugin] serves the Data Portal, REST control channel, optional S3 endpoint and WebDAV. Restricting public portal access does not replace control-channel authentication.
    • [Security] rccSharedSecret signs REST control requests between relays and regular Movers. cliSharedSecret protects a different direct-socket connection; do not confuse the two.
    • [MoverProxy] configures a control-plane HTTP tunnel. It is not an OpenTelemetry exporter or a generic outbound transfer proxy.
    • [ProxySocket] plainText=yes disables TLS on that socket. Keep internal traffic on trusted networks and review TLS verification before exposing it.
    • [Mover] operational affects work availability and test behaviour. The [TestModule] options are not normal production transfer-rate limits.

    Movers follow the Master's transfer-tracing decision and forward completed spans through the existing control connection. They need no OpenTelemetry Collector endpoint, credentials or SDK configuration; see Event Logging.

    For transfer-module settings and per-user portal policy, use the linked references in the dynamic-families section below. Those defaults can affect many transfers, so prefer a Host or User override when only one entity needs a different policy.

    Named socket sections¶

    SocketConfig.load reads the following keys from a component's named section. Common section names for this service are CallBack, RMIServerSocketFactory, RMIClientSocketFactory, FtpPlugin, FTPPassiveSocket, FTPActiveSocket, ECproxyPlugin, ProxySocket, ECauthModule, FtpPASV, FtpPORT, FtpOPEN, HTTPSocketConfig, GCSSocketConfig, S3SocketConfig, WebDavModule, JSftp, TelnetWrapper and ECios. A transfer module or plugin must actually use that socket implementation for its settings to apply; Jetty HTTP listeners and third-party transfer clients do not automatically honour every low-level socket option.

    Basic options inherit the values in [SocketConfig] shown above; the advanced TCP options from tcpCongestion onward default to unset and are read from the named section, not from the global [SocketConfig] defaults. Advanced options depend on OS/socket support. Caller-supplied addresses, ports and module/Host settings may override socket defaults.

    Option(s) Meaning
    listenAddress Local bind/source address.
    publicAddress Advertised address, distinct from the local bind address.
    receiveBufferSize, sendBufferSize Bytes; -1 leaves the OS default.
    soTimeOut Read timeout in milliseconds; aliases soTimeout and timeOut are tried in that order when the preferred spelling is absent.
    connectTimeOut Connection timeout in milliseconds.
    backLog Pending incoming-connection queue length.
    keepAlive TCP keepalive switch.
    tcpNoDelay TCP_NODELAY switch.
    reuseAddress SO_REUSEADDR switch.
    interruptible Use the interruptible socket implementation.
    privilegedLocalPort Allocate a local source/listening port from the configured local range.

    Constructed HTTPS/TLS keys¶

    The HTTPS helper constructs [Security] SSL<Key> names and otherwise consults the corresponding javax.net.ssl.<key> JVM property. Its actual keys are SSLKeyStore, SSLKeyStorePassword, SSLKeyStoreType, SSLTrustStorePath, SSLTrustStorePassword and SSLTrustStoreType.

    SSLTrustStorePath is the HTTPS helper's spelling; the generic socket TLS reader separately uses SSLTrustStore. Do not assume these are aliases. The explicit [HttpPluginSSL] map takes precedence over the HTTPS helper's normal store-selection branch. MQTT uses [Security] SSLKeyStore and SSLKeyStorePassword through its own helper.

    Plugin and module families¶

    [PluginList] is an open map of plugin names to definitions:

    [PluginList]
name=implementation.Class@/path/to/plugin,option=value

    The library path and per-plugin options depend on the plugin. Server plugins support maxConnections and inverseResolution; deleting or adding a plugin definition changes which services start. These are options inside the value, not new top-level ecmwf.properties groups. See Plugin Infrastructure.

    [ECtrans] is an open family of global transfer-option defaults, with keys module.option (for example, ftp.passive). Its option set is defined by ECtransOptions and the selected module, not a fixed list of literal Cnf keys. Entity/transfer setup values can override these defaults. The complete option/default references are:

    • ECtrans common options and the protocol pages under Transfer Modules.
    • Host options, Destination options, Web User options and Data User options.

    These entity options are not interchangeable with service sections. Some options are only meaningful for a particular module or execution role.

    WebDAV initialization parameters¶

    The Mover's WebDAV servlet forwards initialization-parameter lookups to [HttpPlugin] by name. This is an extension family rather than a fixed OpenECPDS enum; unset values defer to the bundled Jackrabbit servlet's defaults. For example, Jackrabbit's missing-auth-mapping parameter is distinct from the OpenECPDS webdavPath listener setting. Only parameters actually read by the bundled servlet apply; arbitrary keys do not become new features.
